# custom-head-util

Кастомная реализация утилиты `head` на языке C. Полная поддержка стандартных флагов, длинных опций, отрицательных значений, суффиксов байтов и нуль-терминированного ввода.

## Сборка

```bash
make          # сборка бинарника head
make clean    # очистка объектных файлов и бинарников
make re       # пересборка (clean + all)
```

## Использование

```
./head [опции] [файлы...]
```

Если файлы не указаны, читает из stdin.

### Опции

| Опция | Описание |
|-------|----------|
| `-n K`, `--lines K` | Вывести первые K строк (по умолчанию 10) |
| `-c K`, `--bytes K` | Вывести первые K байт |
| `-q`, `--quiet`, `--silent` | Не выводить заголовки файлов |
| `-v`, `--verbose` | Всегда выводить заголовки файлов |
| `-z`, `--zero-terminated` | Разделитель строк — нулевой байт (`\0`) вместо `\n` |

### Отрицательные значения

`-n -K` — вывести всё, кроме последних K строк.
`-c -K` — вывести всё, кроме последних K байт.

### Суффиксы байтов для `-c`

| Суффикс | Множитель |
|---------|-----------|
| `b` | 512 |
| `K` | 1024 |
| `M` | 1024² |
| `G` | 1024³ |

Пример: `-c 1K` = 1024 байта.

### Примеры

```bash
./head -n 5 file.txt          # первые 5 строк
./head -c 100 file.txt        # первые 100 байт
./head -c 1M file.txt         # первые 1 мегабайт
./head -n -3 file.txt         # всё, кроме последних 3 строк
./head -q file1.txt file2.txt # без заголовков файлов
./head -v file.txt            # с заголовком файла
./head -z -n 2 file.dat       # 2 нуль-терминированные записи
```

## Тестирование

```bash
make test             # запуск тестов
make test-verbose     # запуск с подробным выводом
```

Тесты сравнивают вывод с системной `head`, проверяют граничные случаи и корректность ошибок.

## Форматирование кода

```bash
make format  # clang-format в стиле Google
```

## Цели Makefile

| Цель | Назначение |
|------|------------|
| `all` | Сборка (по умолчанию) |
| `clean` | Удаление объектных файлов и бинарников |
| `test` | Запуск тестов |
| `test-verbose` | Запуск тестов с `bash -x` |
| `format` | Форматирование кода |
| `deps` | Список и проверка зависимостей |
| `check-deps` | Проверка только обязательных зависимостей |
| `re` | Пересборка |
| `help` | Справка по целям |

## Зависимости

**Обязательные:** `gcc`, `make`, `bash`, `diff`, `head`
**Опциональные:** `valgrind` (проверка памяти), `clang-format` (форматирование), `truncate` (создание разреженных файлов для тестов)

```bash
make deps         # посмотреть статус всех зависимостей
make check-deps   # проверить, что всё необходимое установлено
```
